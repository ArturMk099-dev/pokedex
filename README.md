# Pokédex

A learning project for the Pokédex frontend assignment. The app will display Pokémon data from PokeAPI.

## Current progress

The React 18, TypeScript 5, and Vite starter is ready. React Router v6 is installed for the upcoming pages. The API, list, and detail pages will be implemented step by step.

Live site: not deployed yet.

## Run locally

Use Node.js 24.14.1 or a compatible version supported by the installed Vite release.

```sh
npm ci
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

## Decisions and development notes

- Keep React, TypeScript, and React Router on the major versions required by the assignment.
- Use plain CSS and the browser Fetch API.
- Begin with a minimal page so each feature can be added and explained separately.
- Commit the lockfile; exclude dependencies and build output from version control.
